# SwaadPe 🍽️

SwaadPe is a tiffin-first food platform focused on delivering everyday Indian meals.
Built with FastAPI + modern UI.

## Features
- Customer & Admin login
- Tiffin calendar (Lunch/Dinner)
- Subscription plans
- Swaad Coins

## Tech Stack
- FastAPI
- SQLite / PostgreSQL
- Tailwind CSS
- GitHub-based development

## Run Locally
```bash
uvicorn backend.main:app --reload
